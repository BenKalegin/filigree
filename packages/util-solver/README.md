# @benkalegin/filigree-util-solver

Linear-solver interface stubs shared across [filigree](https://github.com/BenKalegin/filigree) packages.

Holds the `ILinearSolver` shape so layout algorithms that need a solver can depend on the abstract interface without pulling in a concrete implementation. Intentionally tiny.

## Install

```bash
pnpm add @benkalegin/filigree-util-solver
```
