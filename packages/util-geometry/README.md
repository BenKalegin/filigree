# @filigree/util-geometry

Geometry interface stubs shared across [filigree](https://github.com/BenKalegin/filigree) packages.

Holds interface shapes (rectangle arranger, etc.) that concrete implementations in other packages depend on without taking a heavyweight dep on a full geometry library. Intentionally tiny.

## Install

```bash
pnpm add @filigree/util-geometry
```
